# FitLife — Daily Fitness

A responsive front-end UI prototype built with HTML, CSS, and vanilla JavaScript.

## Features
- Login modal (demo feedback only)
- Registration form with browser validation
- Feature cards: Fitness Blog, Diet Planner, Fitness Videos, Payment & Subscription
- Responsive desktop and mobile layout
- Toast messages for demo interactions

## Run locally
Open `index.html` in a browser. No build tools are required.

This is a front-end UI prototype, not a production application. Real authentication, database storage, resume file storage, parking inventory, subscriptions, and payment processing need backend services and secure integrations.
